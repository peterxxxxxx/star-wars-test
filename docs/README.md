# Star Wars Fullstack Application 🌌🚀
*(Aplicación Fullstack de Star Wars)*

---

## 🇺🇸 ENGLISH VERSION

### 📝 Project Overview
This is a comprehensive web application for managing and visualizing characters from the Star Wars franchise. The project is developed as a technical assessment focusing on software architecture, code efficiency, and service integration.

### 🛠 Tech Stack
- **Backend:** Python with **Flask** framework.
- **ORM:** SQLAlchemy for efficient database management.
- **Frontend:** **Vue.js 3** (Composition API).
- **Database:** **PostgreSQL** hosted on **Vercel Neon**.
- **Deployment:** (In Progress) Vercel for hosting and Vercel Blob for multimedia storage.

### 🚀 Phase 1 Progress: Data Consumption & Base Visualization
- [x] **API Configuration:** Implemented a backend endpoint with server-side pagination logic.
- [x] **Filtering System:** Name-based search functionality integrated via backend queries.
- [ ] **Base Interface:** (Coming next) Card-based visualization with name and photography.

### 📋 Installation (Backend)
1. Navigate to `/backend`.
2. Create and activate a virtual environment: `python -m venv venv`.
3. Install dependencies: `pip install -r requirements.txt`.
4. Run the server: `python app.py`.

## 🇲🇽 VERSIÓN EN ESPAÑOL

### 📝 Resumen del Proyecto
Esta es una aplicación web integral para la gestión y visualización de personajes de la franquicia Star Wars. Desarrollada como una prueba técnica, el enfoque principal es la arquitectura de software, la integración de servicios y la eficiencia del código.

- **Backend:** Python con el framework **Flask**.
- **ORM:** SQLAlchemy para la abstracción de la base de datos.

- **Base de Datos:** **PostgreSQL** alojado en **Vercel Neon**.
- **Despliegue:** (En proceso) Vercel para hosting y Vercel Blob para almacenamiento de imágenes.
